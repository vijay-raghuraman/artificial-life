# Artificial Life

## CI/CD

### Build Only

To only build the project:

```bash
make all
```

or just:

```bash
make
```

### Build & Run

To build (if needed) & run the project:

```bash
make run
```

### Test

To run the test files:

```bash
make test
```

### Clean

To clean the build files:

```bash
make clean
```
